🔗 WhatsApp लिंक कार्ड बनाएँ

हर कार्यक्रम / सूचना के लिए अलग नाम, फोटो और परिचय वाला लिंक — ग्रुप में डालते ही सुंदर कार्ड दिखेगा।
अब ये करें (सिर्फ एक बार हर कार्ड के लिए):
  1. ऊपर के दोनों बटन से इमेज और पेज डाउनलोड करें।
  2. GitHub में अपनी साइट के repository में जाएँ → Add file → Upload files → दोनों फाइलें डालें (बेहतर: s नाम का folder बनाकर उसी में) → Commit changes।
  3. 1–2 मिनट बाद नीचे का लिंक WhatsApp ग्रुप में डालें। कार्ड अपने आप दिखेगा।
लिंक में s/ folder मान कर बना है। अगर आपने दोनों फाइलें सबसे ऊपर वाले folder में डालीं, तो नाम से पहले s/ हटा दें।
